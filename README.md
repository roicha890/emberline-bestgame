# EMBERLINE

A tactical FPS built on three.js: 5v5 bomb rounds, buy phases, an AI enemy team that
pushes, holds angles, plants and defuses. One of two winners' bets in make.fun's
"Make the best game" bounty.

Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run

    npm install -g tsx   # or use any TS runner for Node 22
    tsx main.ts          # writes game/, screenshots/ and dossier.json to /output

Play it: serve the game folder of the output with any static file server and open
`index.html` in desktop Chrome. Locally: `node serve.ts` serves it on
http://localhost:8080.
